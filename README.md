# Used Car Price Prediction

## Project Overview
This Machine Learning project predicts the estimated selling price
of a used car based on its features.

## Objectives
- Predict used car selling prices.
- Understand the relationship between car features and selling price.
- Build an interactive web application.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Linear Regression
- Streamlit
- GitHub
- Streamlit Community Cloud

## Input Features
- Manufacturing year
- Present price
- Kilometres driven
- Fuel type
- Seller type
- Transmission
- Previous owners

## Machine Learning Algorithm
Linear Regression

## How to Run Locally
1. Install Python.
2. Install the libraries using:
   pip install -r requirements.txt
3. Keep app.py and car data.csv in the same folder.
4. Run:
   streamlit run app.py

## Disclaimer
Predictions are estimates and may differ from actual market prices.
